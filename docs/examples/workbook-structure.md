few data rows, exactly as they appear in the file. Long cells are truncated with
an ellipsis; the real cells are not. The workbook itself carries the formatting
this page cannot: freeze panes at A3, collapsible row outlines (the `+` margin),
zebra striping, status dropdowns and conditional tints, and print setup that fits
to page.
